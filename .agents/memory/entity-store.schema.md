# entity_store.json — schema

An index, not a source of truth. Every path it lists must also exist as a
readable file or be generated by named code. If a path here goes stale, the
index is lying — same failure as a queue status that disagrees with git, and it
is the reason this file carries an `updated` date.

The index itself is optional. This file is the *shape*; a project that does not
need an entity index simply does not have one, and nothing in the office breaks.

## Shape

```jsonc
{
  "version": 1,                 // bump on any breaking reshape
  "updated": "YYYY-MM-DD",      // last time a listed path was verified to exist
  "people":   { "<name>": { "role": "…", "ref": "…path…" } },
  "personas": { "<role>": { "file": "…", "hired": "…" } },
  "rules":    { "<name>": "…path…" },
  "prompts":  { "<name>": "…path…" },
  "harnesses":{ "<dir>": "what it is" },
  "artifacts":{ "<name>": "…path…" }
}
```

A generic example, for a project called `acme`:

```jsonc
{
  "version": 1,
  "updated": "2026-01-01",
  "people": {
    "founder": { "ref": ".agents/memory/founder.md", "role": "owner" },
    "zolly":   { "ref": ".agents/memory/goal.md", "role": "manager" },
    "foreman": { "role": "team leader; the only dispatcher" }
  },
  "personas": {
    "generic": { "file": ".agents/worker/generic.md" }
  },
  "rules":    { "system": ".agents/rules/system.md" },
  "prompts":  { "triage": ".agents/prompts/task_triage.md" },
  "harnesses": { ".omp/": "tool commands and persona files" },
  "artifacts": { "memory-cli": ".agents/shared/memory" }
}
```

## Rules

1. **Paths only, no content.** A fact stored here and nowhere else is lost to
   the next agent. The pointed-at file holds the fact.
2. **`updated` is a claim.** Bump it only after checking the paths resolve.
3. **No secrets.** Same refusal as `.agents/shared/memory add`.
4. **A founder decision is not here.** It goes in `OPEN-QUESTIONS.md` and is
   deleted when answered. One register, one place.

## Why this is keyed by entity

`.agents/memory/` is already split by *question* — `decisions.md` (what was
decided), `learnings.md` (what was wrong), `current.md` (what is in flight).
That is the right split and it is owned by `.agents/shared/memory`, which
enforces bounds and atomic writes.

What had no home was **keyed by thing rather than question**: who the agents
are, where their persona lives, which directory is harness and which is agent,
which artifacts are load-bearing. That is what this file indexes. It deliberately
adds no fourth question — see `.agents/rules/learned.md`.

## Daily logs are not duplicated here

If the project keeps per-tick JSON transcripts, they live in their own
directory. There is deliberately **no** second `daily_logs/` directory: adding
one would be the duplicate-store failure `.agents/memory/README.md` warns about.
